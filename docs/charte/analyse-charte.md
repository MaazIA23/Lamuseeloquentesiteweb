# Analyse de la charte graphique — La Muse Éloquente

Source : `Charte graphique LME` (33 pages, Adobe Illustrator, oct. 2025, réalisée par
Ulrich GANSE). Extraits de référence dans ce dossier (`*.webp`).

## 1. Identité

- **Vision** : devenir la référence incontournable en Afrique et au-delà dans
  l'accompagnement à l'éloquence et à l'impact professionnel ; d'ici 2035, l'agence de
  référence qui transforme la communication des individus et des organisations.
- **Mission** : révéler et développer le potentiel oratoire des individus et des
  organisations (programmes sur-mesure, accompagnements personnalisés, événements
  fédérateurs). « Nous mettons l'art de l'éloquence au service de la performance
  professionnelle et de l'impact social. »
- **Valeurs** : Intégrité · Responsabilité · Impact.
- **Signature** (carte de visite, roll-up) : « Éloquence & Impact ».

## 2. Logo

- Construction : **visage stylisé + micro + cercle** = pictogramme.
- Logotype : « La Muse » en script doré (Accountant Signature) + « ÉLOQUENTE » en
  capitales condensées noires.
- Versions : **verticale (principale)** et horizontale ; couleur, noir, blanc, monochrome.
- Taille minimale : **25 px**. Périmètre de sécurité défini (p. 11).
- Pictogramme seul (icône app / favicon) : carré arrondi bleu, or, ou blanc bordé.
- Interdits : changer les couleurs, déformer, compresser, rogner, modifier la
  construction, enfermer dans une forme, poser sur un fond proche de sa couleur.
- Fond plus foncé que 50 % de gris → logo blanc.

## 3. Couleurs

| Rôle | Nom proposé (tokens) | Hex |
|---|---|---|
| Principale | `--lme-bleu` | **#272A5D** |
| Principale | `--lme-or` | **#B48028** |
| Dégradé doré | `--lme-or-clair` → `--lme-or-moyen` → `--lme-or-profond` | **#E7C26D → #B8822B → #7F5A24** |
| Secondaire | `--lme-jaune` | #F5C036 |
| Secondaire | `--lme-bleu-lavande` | #5363AB |
| Secondaire | `--lme-turquoise` | #1A9399 |

- Le bleu = confiance, professionnalisme. Le dégradé doré = élégance, lumière, prestige.
  Le marron/or profond = stabilité, authenticité.
- Fond des supports de la charte : **blanc cassé texturé** (lignes fines façon papier
  gaufré) avec un **fil doré ondulé** qui traverse les pages → signature graphique.

## 4. Typographies

| Rôle (charte) | Police | Disponibilité web |
|---|---|---|
| Titres principaux | **Anton** | Google Fonts, libre ✔ |
| Accent manuscrit | **Accountant Signature** | Police commerciale — fichier + licence web à fournir |
| Texte courant, sous-titres | **Gotham** (ExtraLight → Black) | Commerciale (Hoefler&Co) — licence web payante |
| Secondaire display | **Haettenschweiler** | Police système Windows — licence web à vérifier |

Constat : les pages de la charte elle-même utilisent aussi **Maven Pro** (titres de
sections), **Montserrat** et **Poppins** (texte), toutes libres sur Google Fonts.

**Proposition web** : Anton (titres) + **Montserrat** comme substitut libre et très
proche de Gotham (texte) + Accountant Signature en fichier auto-hébergé si la licence
le permet (usage parcimonieux : mots-accents, signature). À valider.

## 5. Éléments graphiques

- **Patterns** : motif doré répétitif (micros / visage) sur fond blanc.
- **Fil doré ondulé** (pages de section) → à réutiliser comme fil conducteur animé.
- **Barre de pied de page** : filet noir + pastille bleue numérotée → vocabulaire
  réutilisable pour les numéros de section.
- **Branding** : cartes de visite, papier à en-tête (bandes bleues diagonales),
  signature mail, bloc-notes, tote bag, roll-up.
